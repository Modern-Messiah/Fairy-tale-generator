# Разработка

Команды собраны в `justfile` в корне репозитория. Список: `just --list`.

## Что нужно

- Node.js 22
- Docker с Compose
- [just](https://github.com/casey/just)

Ключ модели нужен только для живой генерации. Тесты и сборка проходят без него.

## Первый запуск

```bash
just setup
just dev
```

`just setup` создаёт `.env` из примера, ставит зависимости, поднимает PostgreSQL и применяет миграции. Сервер открывается на http://localhost:3000.

В `.env` заполните `XAI_API_KEY`, если нужна генерация. Модель по умолчанию `grok-4.7`, другое имя задаётся через `XAI_MODEL`. Ключ читает только сервер.

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | PostgreSQL. Локально `postgresql://story:story@localhost:5432/storydb` |
| `XAI_API_KEY` | Ключ xAI. Пустое значение даёт ответ 503 на генерацию |
| `XAI_MODEL` | Имя модели, по умолчанию `grok-4.7` |

Полный подъём приложения и базы в контейнерах: `just up`. Образ сам применяет миграции перед стартом.

## Команды

| Команда | Действие |
| --- | --- |
| `just setup` | `.env`, `npm install`, база и миграции |
| `just dev` | Сервер разработки |
| `just test` | Тесты Vitest |
| `just lint` | ESLint |
| `just check` | Тесты и линтер |
| `just build` | `prisma generate` и production-сборка |
| `just start` | Запуск собранного приложения |
| `just db` | Только PostgreSQL |
| `just migrate` | База и `prisma migrate deploy` |
| `just up` | `docker compose up --build` |

Тесты не вызывают модель и не подключаются к базе. Поток генерации проверяется с подменённым генератором.

## Устройство

- `src/domain` — каталог героев и жанров, проверка запроса, тексты интерфейса, промпты и разбор потока. Этот слой без базы и без ключа.
- `src/server` — окружение, Prisma и вызов xAI.
- `src/app` — страницы и маршруты API.
- `src/components` — форма, поток на той же странице, история и переключатель языка.
- `prisma/` — схема `Story` и миграции. Адрес базы задаётся в `prisma.config.ts`, не в `schema.prisma`.

Браузер обращается только к Next.js. Генерация идёт на `/` и не начинается заново после обновления страницы. Кнопка «Параметры» возвращает к форме с теми же значениями.

## Язык

Cookie `ui-locale` хранит язык интерфейса: `ru` или `kk`. Любое другое значение считается русским. Переключатель в шапке подписан «Русский» и «Қазақша» на обоих языках.

Поле «Язык сказки» выбирает язык текста. У новой формы оно совпадает с языком сайта. Сообщения API остаются на русском. Казахский интерфейс переводит известные строки у себя.

## HTTP

`GET /api/health` не требует базу. Ответ: `{ "status": "healthy", "modelConfigured": true }` или `false`.

`GET /api/stories?page=1` возвращает страницу истории. В элементе есть превью и `createdAt` в ISO, полного текста нет. На странице 9 сказок.

`GET /api/stories/:id` возвращает сказку вместе с текстом. Неизвестный id даёт 404 `{ "error": "Сказка не найдена" }`.

`DELETE /api/stories/:id` удаляет сказку и отвечает `{ "ok": true }`.

`POST /api/stories` принимает JSON:

```json
{
  "age": 7,
  "language": "ru",
  "genre": "adventure",
  "characters": ["Заяц", "Волк"]
}
```

Возраст — целое от 1 до 10. Язык — `ru` или `kk`. Жанр — одно из значений каталога. Персонажей от 2 до 5, без повторов, имена из каталога, каждое не длиннее 50 символов.

Ошибки запроса:

| Код | Когда |
| --- | --- |
| 400 | Тело не JSON. `{ "error": "Некорректный JSON" }` |
| 422 | Поля не прошли проверку. `{ "error": "Проверьте поля формы", "issues": [...] }` |
| 503 | Нет ключа модели. `{ "error": "Ключ модели не настроен" }` |

Успешный ответ — поток `text/event-stream`. События приходят строками `data: ...`.

```text
data: {"chunk":"..."}

data: {"done":true,"storyId":12}
```

Ошибка генерации: `data: {"error":"..."}`. Пустой текст и оборванный запрос не сохраняются. Текст длиннее 100 000 символов обрезается и всё равно сохраняется, если генерация дошла до конца.
